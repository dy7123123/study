# 消息监听设计文档：用户行为记录监听任务

## 一、功能概述

本监听任务用于实时接收订单完成的消息，并将订单信息记录到用户行为表中，便于后续进行用户行为分析与数据追踪。该任务通过监听 RabbitMQ 消息队列实现消息消费，自动化入库，无需人工干预。

## 二、消息结构说明

监听的消息为 JSON 格式，示例如下：

```java
{
        "pin": 109,
        "orderId": "1",
        "venderId": 1,
        "orderCompletedTime": 1627110516000
        }
```
字段说明：
pin：用户唯一标识
orderId：订单编号
venderId：商家ID
orderCompletedTime：订单完成时间（时间戳，单位：毫秒）

## 三、功能实现

- **任务名称**：用户行为记录监听任务（UserOrderBehaviorListener）
- **监听方式**：RabbitMQ 消息队列监听
- **技术方式**：使用 Spring Boot + RabbitMQ 实现消息消费功能，使用 @RabbitListener 注解监听指定队列 
- 
```java
@RabbitListener(queues = "order.complete.queue")
```
- **需要的接口**：UserBehaviorService
- UserOrderBehaviorMapper

- **实现逻辑**：
  - 1. 从指定队列中接收订单完成消息
  - 2. 将 JSON 消息反序列化为 Java 对象
  - 3. 提取关键信息写入数据库
  - 4. 记录原始消息和处理时间
- **日志和异常处理**：每条消息处理前后均记录日志，内容包括订单ID、用户PIN、处理状态；错误日志记录详细堆栈信息，便于追踪。
